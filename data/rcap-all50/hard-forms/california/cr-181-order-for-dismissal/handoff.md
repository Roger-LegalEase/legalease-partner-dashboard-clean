# CA CR-181 / CR-410 — proposed orders (Tier 1)

Both forms are the **proposed orders** that accompany their petitions. The
participant completes the caption and nothing else: every relief-disposition
box and the judicial signature is protected, so a LegalEase packet can never
appear to pre-decide relief a judge has not granted.

- **CR-181** Order for Dismissal — serves ca-1203-41/42/43/4a and
  ca-17b-reduction. Source sha256 `f737503a…`, XFA, 2pp. 58 fields:
  12 bound (caption), **42 protected**, 4 available.
  The protected set includes the PC 1203.4 / 1203.4a / 1203.41 / 1203.42 /
  1203.43 / 1203.49 grant boxes and the 17(b)/17(d)(2) grant-and-deny pairs.
- **CR-410** Order to Seal Arrest and Related Records — serves ca-851-91.
  Source sha256 `d94bd94b…`, XFA, 1p. 26 fields: 3 bound (caption),
  **23 protected**, 0 available.

## What F must visually approve

1. On every fixture, all disposition boxes and both signature blocks are
   visibly blank.
2. Caption values sit inside their rectangles at boundary lengths.
3. The negative fixture, which supplies almost nothing, still produces a clean
   blank order rather than a partially-stamped one.
