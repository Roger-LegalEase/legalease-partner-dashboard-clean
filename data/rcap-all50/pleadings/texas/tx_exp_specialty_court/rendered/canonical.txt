PETITION FOR STREAMLINED EXPUNCTION ORDER AFTER SPECIALTY COURT DISMISSAL (TEX. CODE CRIM. PROC. ART. 55A.203)

STATUTORY AUTHORITY

Tex. Code Crim. Proc. art. 55A.203 — The streamlined route. Where a case was dismissed following successful completion of a veterans treatment court programme under Gov't Code ch. 124 or a mental health court programme under ch. 125, a DISTRICT COURT may, with the consent of the attorney representing the state, enter an expunction order not later than the 30th day after the dismissal or after it receives the dismissal information.
Tex. Code Crim. Proc. art. 55A.203(c) — A court entering an order under the article may not charge any fee or assess any cost for the expunction.
Tex. Code Crim. Proc. art. 55A.203(d) — Added by S.B. 1667. The person must provide the court with the information required in an art. 55A.253 petition. That is what the information package component carries.
Tex. Code Crim. Proc. art. 55A.053(a)(2)(A) — One of the two entitlement grounds. The underlying entitlement lives here, not in art. 55A.203.
Tex. Code Crim. Proc. art. 55A.053(a)(2)(B) — The other entitlement ground.
Tex. Code Crim. Proc. art. 55A.053(b) — Recorded in the track authority.
Tex. Code Crim. Proc. art. 55A.053(c) — Recorded in the track authority. A person may receive only one expunction on each ground and must file an affidavit attesting to that fact.
Tex. Code Crim. Proc. art. 55A.253 — Supplies the required information the art. 55A.203(d) information package must carry, and the verification requirement.
Tex. Code Crim. Proc. art. 102.0061(d) — Requires waiver of the district-court filing fee where entitlement arises under art. 55A.053(a)(2)(A) or (B) — a second, independent no-cost provision alongside art. 55A.203(c).
