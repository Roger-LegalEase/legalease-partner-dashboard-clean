VERIFIED APPLICATION FOR EXPUNCTION ON THE GROUND OF MISTAKEN IDENTITY (TEX. CODE CRIM. PROC. ARTS. 55A.006 AND 55A.256)

STATUTORY AUTHORITY

Tex. Code Crim. Proc. art. 55A.006 — The ground. Relief is available where the person was arrested solely because identifying information was inaccurate due to clerical error, or where another arrested person falsely gave the applicant's identifying information without consent and that deception is the only reason the applicant's information is in the records. It operates notwithstanding the art. 55A.001 arrest requirement, so the applicant need not have been arrested at all.
Tex. Code Crim. Proc. art. 55A.256 — The vehicle. A verified application, including authenticated fingerprint records, filed with the attorney representing the state in the prosecution of felonies in the county where the applicant resides or where the offence was alleged to have occurred. This is not a petition and it is not filed with a court.
Tex. Code Crim. Proc. art. 55A.256(b) — Prescribes the contents of the application, and makes authenticated fingerprint records a mandatory part of it.
Tex. Code Crim. Proc. art. 55A.256(c) — After verifying the allegations the prosecutor supplements missing arrest information, forwards the application to the district court with the agency list attached, and requests the order.
Tex. Code Crim. Proc. art. 55A.256(c-1) — The S.B. 1667 anti-duplication rules apply to the application: no state or local agency listed more than once, and no separate contacts or addresses for divisions of the same agency.
Tex. Code Crim. Proc. art. 55A.256(d) — The court enters a final order WITHOUT A HEARING, because the prosecutor has already verified the application upstream.
Tex. Code Crim. Proc. art. 55A.354 — The effect, and it is narrower than ordinary expunction. Agencies obliterate the applicant's identifying information and substitute the arrested person's information. They do not return or destroy the file, and index references are not deleted.
Tex. Code Crim. Proc. art. 55A.001 — The general arrest requirement, which art. 55A.006 expressly operates notwithstanding.
