# C2 automatic-stage / court-petition split

This lane retains each genuine automatic process as a non-fileable Category B stage and identifies a separate participant court-filing backstop where the committed record permits it. It completes 21 of 25 assigned routes: seven reuse existing Category A routes and fourteen create new branch identities. Four routes are stopped and reported because the exact participant instrument is incomplete or unresolved.

No packet family is created here. No route is opened for checkout, sponsored generation, credit consumption, attachment, delivery, or repeat download.
