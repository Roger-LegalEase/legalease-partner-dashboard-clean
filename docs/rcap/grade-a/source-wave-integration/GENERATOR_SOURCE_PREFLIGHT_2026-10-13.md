# Factory and conveyor source dependency preflight

This is an execution dependency inventory of the existing generators, not a new
legal audit, packet build, source revision or acceptance decision. Original
receipts, source bytes, geometry, output hashes and commercial holds remain intact.

The reviewed inventory is
`data/rcap-grade-a/source-custody/generator-preflight-20261013/manifest.json`.
It binds the five existing convergence entrypoints, their static imports, and the
invoked `verify-packet-build-environment.mjs` child: 39 modules. It follows 36
original receipt/custody records to 77 required source files, including 23 private
files. Each source retains pointers into the unchanged original records, exact
SHA-256 and length. The Ohio pair is one part of this inventory:

Both URLs come from the retained Ohio author handoff. Actual downloads matched
both original pins. The original Ohio font/package, September adoption and SC
restoration mechanisms are preserved and run first. The shared preflight reports
all missing/mismatched required files together, downloads only missing private
files with the designated original official transport, and installs nothing
until its inventory verifies. It never overwrites existing files, restores a
tracked source by download, follows destination symlinks, or invents a hash.

The child's conditional corpus sample also matters. The original corpus index
contains 1006 distinct paths across several custodies. The preflight authenticates
that index and checks every present indexed file. Absent catalog entries remain
explicitly `NOT_PRESENT_NOT_READ`; they are not reported verified, nor converted
into new mandatory recovery of an unmounted operational corpus. The unchanged
child environment check still evaluates its own sample and reports availability.
Catalog entries used only for discovery are distinct from mandatory source reads.

Both workflows then use `check-generator-convergence.mjs` to execute all five
unchanged `--check` commands. A read guard, inherited by Node child processes,
requires every actual private source read to match either the mandatory inventory
or the authenticated corpus index. All child receipts are aggregated, including
failed reads caught by a generator adapter. Any refused receipt fails convergence;
a successful parent exit cannot hide it. Each command's actual result and logs
are retained outside the checkout and uploaded as evidence, without source bodies.
No generator assertion or layout/acceptance requirement is relaxed.

Seventeen targeted controls cover aggregate missing-file reporting, exact positive
restoration/idempotence, mismatch/no-partial-install behavior, changed custody,
transport and module graphs, omitted dependencies, ignored-path/symlink protections,
conditional index identity, and swallowed child refusals. A separate real-original
positive verifies both Ohio court downloads and idempotent installation. Full
local convergence remains dependent on the unmounted local Master/adoption inputs;
fresh CI is the integration verdict. New source-reading code changes require a
reviewed inventory update rather than an unverified automatic hash refresh.
