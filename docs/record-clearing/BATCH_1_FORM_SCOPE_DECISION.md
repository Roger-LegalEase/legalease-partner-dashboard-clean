# Batch 1 Form-Scope Decision

**Applies only to Batch 1:** Alaska, Alabama, Arkansas, Arizona, California, Colorado, Connecticut, District of Columbia, Delaware, Florida, Hawaii, and Idaho.

## Owner instruction

For LegalEase's Batch 1 packet-library build, a form that is not included in the supplied Batch 1 source set is treated as **not required for the Batch 1 implementation**. No further form should be added to a Batch 1 missing-form list solely because an earlier review named it but it was not supplied in the completed Batch 1 source handoff.

This is a product-scope and source-corpus decision. It does not, by itself:

- make a supplied form current, statewide, or approved for runtime use;
- convert a local packet into a statewide form;
- resolve a true legal-design question about the governing mechanism, output strategy, venue, or pleading contents;
- replace source, legal-output, technical, or visual approval.

Files already marked `source-gated` remain gated until their stated currentness, geography, or legal-output issue is resolved.

## Batch 2 and Batch 3

Batch 2 and Batch 3 legal reviews and source collection are still in progress. This Batch 1 closure does not declare the nationwide form library complete and must not be applied to Batch 2 or Batch 3 before those reviews are finished.
