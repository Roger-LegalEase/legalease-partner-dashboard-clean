# RCAP source packs

Generated by `scripts/generate-rcap-source-packs.mjs`. Do not edit by hand.

A source pack is the court's own PDFs, at their canonical Master Library paths, for one batch of
four to eight families. It carries nothing else. A fixture, contact sheet, raster, sample packet or
any other LegalEase output inside a pack looks exactly like the court's form until somebody renders
from it, and then every artifact in the batch is derived from our own previous output — so a source
that is absent, or that does not hash to what its family's record pins, fails its pack. Nothing is
substituted for it, and a partial pack is not written.

The built ZIPs are ignored output. They hold official court PDFs, which are not this repository's to
redistribute, so they are written to `tmp/source-packs` — a path the factory proves git-ignored
before it writes anything, and refuses to build into otherwise. What is committed is the manifest:
the canonical path, digest, byte length and visible form expectation each packed file must satisfy.

## Running it

```
node scripts/generate-rcap-source-packs.mjs            # manifests only
RCAP_BUNDLE_EXTRACT=/path/to/Expungement_AI_RCAP_Master_Library_Edition_1 \
  node scripts/generate-rcap-source-packs.mjs --build  # manifests + ZIPs
node scripts/generate-rcap-source-packs.mjs --check    # committed manifests are current
```

`RCAP_SOURCE_PACK_OUT` moves the ZIP directory. Each pack ships an `install.sh` that verifies every
file against the pack's own `manifest.json` before placing it, and refuses the whole run on a
mismatch. `scripts/verify-rcap-source-packs.mjs` proves each refusal against a synthetic corpus and
removes each one in turn to prove the canary watching it goes red.

## The families no pack can carry

24 non-retired families name no canonical Master Library path at all, so their bytes have to come from the publisher. They cannot appear in a pack and nothing above waits on them.

the register reports missingPdfBinaries = 37, and origin/main reports the same figure, so nothing on this branch moved it. Those two counts answer a different question from this one: this factory asks whether the official bytes can be packed. 13 of that population reconcile to a Master Library asset by sha256 — their bytes are in the library at a named canonical path, under the digest their own record pins — so they are packed here rather than acquired. That leaves 24 families with no library path at all, and those are the real acquisition targets. The assignment's controlling fact is 37. This factory adjudicates no denominator and hand-edits no total: it records each number, what each counts, and how each was derived.
